# Production interface

All authored work lives in this folder. Blender 5.1.1 and Unreal 5.8.3 are the installed applications. Procedural character and motion authored specifically for this assignment; no third-party body or motion.

Blender meters, X is character right, facing -Y, Z up. Unreal centimeters, facing +X, anatomical right -Y, Z up. Standing neutral body spans Z=0..1.80. Export explicitly scales mesh vertices, shape keys, bind positions and bone translations from meters to centimeters; FBX uses -Y forward and Z up, with Unreal import scale 1. The verified legacy importer maps source (x,y,z) to Unreal (-100y,-100x,100z).

Authoring rig object `Operative_Rig`, deform bones root, pelvis, spine_01, spine_02, chest, neck, head; clavicle.L/R, upper_arm.L/R, forearm.L/R, hand.L/R; thigh.L/R, shin.L/R, foot.L/R, toe.L/R; thumb/index/middle/ring/pinky_01/02/03.L/R; eye.L/R, jaw, tongue, brow.L/R, lid_upper.L/R, lid_lower.L/R, lip_upper, lip_lower, lip_corner.L/R, cheek.L/R, cable_01/02/03, cell, beacon, blade. The fitted rig includes twist bones and 79 deformation bones in total. The retained Blender export skeleton is `Operative_Export_Skeleton`; its FBX armature node is `Armature`, which the legacy importer removes. Unreal uses `Operative_Skeleton`. Source names ending .L/.R become _L/_R on import.

Ground root at (0,0,0). Pelvis (0,0,.94), spine_01 (0,0,1.05), spine_02 (0,0,1.17), chest (0,0,1.30), neck (0,0,1.46), head (0,0,1.52). Shoulders (+/- .19,0,1.39), elbows (+/-.34,0,1.15), wrists (+/-.40,-.015,.94), hand end (+/-.42,-.035,.85). Hips (+/-.10,0,.94), knees (+/-.11,-.025,.53), ankles (+/-.11,0,.10), toes (+/-.11,-.14,.04).

Motion module `source/generators/motions.py`: export `pose_at(name, t, duration)` returning dictionary with pelvis=[x,y,z] ABSOLUTE, torso=[rx,ry,rz] radians, chest=[rx,ry,rz], head=[rx,ry,rz], hands={L:[x,y,z],R:[x,y,z]} ABSOLUTE wrist positions, feet={L:[x,y,z],R:[x,y,z]} ABSOLUTE ankle positions, foot_rot={L:[rx,ry,rz],R:...}, poles={elbow.L:pos, knee.L:pos,...}, curls={L:[five curl values 0..1],R:...}, root=[x,y,z] translation (only dash), face={control:value}, cell/beacon positions optional ABSOLUTE, or position/rotation dictionaries for oriented contact; omitted prop targets follow their fitted mount. blade=0..1. Missing values use rest defaults. `entry_metadata(row)` provides duration, events (frame/time/name), speed_cm_s, layer, entry_state, exit_state. `expression_presets` dictionary. Functions are bpy-independent; main applies and keys animator controls then bakes deformation actions. Facial controls use deform bones plus morph targets; bones provide imported action speech coverage.

Named baked FBX clips `export/animations/{ID}.fbx`, authored source action `{ID}`, export deformation action `BAKED_{ID}`. Unreal mesh `/Game/Operative/SK_Operative`, skeleton `/Game/Operative/Operative_Skeleton`, animations `/Game/Operative/Animations/{ID}` (exact names import ensured by importer). Mesh uses <=8 material slots including props; textures under source/textures and export/textures. LOD1/2 in export/Operative_LOD1.fbx and Operative_LOD2.fbx.

Unreal C++ owns integrated native animation instance/controller with layered pose blends, root-motion capsule handling, face override controls and slope IK; generated assets are actual imported FBX. Data mirror `unreal/Content/Data/animation_manifest.json` and `dialogue_alignment.json`, audio imported `/Game/Operative/dialogue`. Use relative project paths. Controls and build commands documented. Project name MorphRig, C++ module MorphRig. Main map `/Game/Showcase/Showcase`.

The source generators create the character from mesh data and intentional pose/contact curves. No other character or motion service was used. The finished .blend retains editable source actions and the corresponding centimeter deformation bakes; rebaking selected edited actions does not recreate geometry.
